# petamoru-web

Public legal pages of Petamoru, served by GitHub Pages at `petamoru.com`.

| Path | File |
|---|---|
| `/privacy` | `privacy.html` |
| `/terms` | `terms.html` |

The paths are fixed by CA-1.2.2 of the app's SPEC: the app links to them, so they must not change.

Fonts are the app's own (Inter and Nunito Sans, OFL), self-hosted so the pages make no third-party requests.
